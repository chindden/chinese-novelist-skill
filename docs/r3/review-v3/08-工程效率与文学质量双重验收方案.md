# 08 · 工程效率与文学质量双重验收方案

> **文档版本**：`v1.2.3 (Freeze-Ready Final)`  
> **核心纪律**：
> 1. **严禁将自动化单元测试通过、哈希校验通过或 CLI 加速描述为“文学质量提升”！**
> 2. **严禁将历史校准集与独立 Holdout 合并统计**：G2 必须严格拆分为 **`G2-A Regression/Calibration`** 与 **`G2-B Independent Holdout`**，分别报告原始 `TP/FP/FN/TN`、Precision、FPR 与聚类 95% CI；**历史校准数据通过，绝不等于独立 Holdout 通过**；新样本不足时强制标 `underpowered`，绝不降门槛或包装为通过。
> 3. **严禁混淆独立章节数（$N_{\text{ch}}$）、独立案例数（$N_{\text{case}}$）与重复运行次数（$K_{\text{rep}}$）**；同一章节内多个缺陷不能当作多个独立章节；`B = 2,000` 次 Bootstrap 仅是重抽样数值计算，绝不能弥补独立章节数不足。
> 4. **严禁把静态扫描等同于运行期零写入**；L0 三重验证任何一项未通过，均不得宣称已证明零写入。
> 5. **严禁将离线测试集的 Precision 直接推断为生产环境 Precision**，亦不得将 G6 有限预算工程准入筛查包装为“统计学上证明了生产召回率达到 90%”。
> 6. 本方案强制实行**双轨独立验收（Track E 工程与效率验收 × Track L 审核准确度与文学质量验收）**——任一轨道未过线，均不得宣称 v3 架构验收通过或替代现行基线。

## 二、Track L：审核准确度与文学质量验收（三方案对照 + 聚类统计 + 多评委一致性）

### 1. 阶段一：P0-6 三方案离线对照与统计稳健 G1–G6 门禁（准入主仓硬门槛）

#### 1.1 三方案（A / B / C）同台对照与胜出裁决规则（不预设双阶段必胜）
在同一批验证集上并行评测：
- **方案 A**：增强单阶段完整审稿（生产底座 + v2.2 融合 + `precheck v2` + `PLANNING_CONFLICT_BLOCK` + 6 维最小取证槽）；
- **方案 B**：Pass 1 开放发现（含 6 维取证槽 + `NEEDS_SEMANTIC_AUDIT` 强制核销）+ Pass 2 独立轻量定级；
- **方案 C**：单阶段完整审稿（高召回偏置）+ 独立轻量定级复核（`PASS` 章短路跳过）。

**裁决硬规则**：
1. 仅允许**同时通过全部 G1–G6 门禁（含 G2-A 与 G2-B 分别达标）**的方案进入候选胜出池；若三者均未全过或 `G2-B` 仍处于 `underpowered` 未补齐，**禁止强行合入主仓**。
2. 若**方案 B** 的 G1 或 G6 召回率低于方案 A 或 C 超过 `1.0 pp`、或出现任何 **1 例 `BLOCKER` 漏检**（证实“Pass 1 漏检无法被 Pass 2 找回”），**直接淘汰方案 B**。
3. 若多个方案同时全过 G1–G6，按优先级选优：**① G6 跨题材 `BLOCKER` 零漏检 & 召回最高 → ② G2-B 独立 Holdout FPR 最低且三轮方差最小 → ③ 端到端审稿延迟最低**。

#### 1.2 统计独立性、历史集与独立集隔离及方法学硬约束（六条不可突破纪律）
1. **严格隔离历史校准集与独立 Holdout（严禁混合统计）**：
   - 曾参与规则设计、调参或评委迭代的历史样本归入 **Regression / Calibration（回归与校准稳定性轨道）**；
   - **从未参与任何规则设计、调参或仲裁的全新章节**单独归入 **Independent Holdout（独立泛化验证轨道）**；
   - **两组必须分别报告原始 `TP / FP / FN / TN`、Precision、FPR 与章节级聚类 Bootstrap 95% CI**，**严禁将两组结果混合后作为跨章节独立泛化能力的证明**；**历史校准数据通过，绝不等于独立 Holdout 通过**。
   - 若现有独立新样本不足以满足 G2-B 统计要求，**必须显式标记 `underpowered` 并逐项列明还需补充的独立章节数与案例数**，绝不降低原有门槛，绝不将不足样本包装为通过。
2. **严格分列三元组：独立章节数（$N_{\text{ch}}$）× 独立案例数（$N_{\text{case}}$）× 重复运行次数（$K_{\text{rep}}$）**：
   - **同一章节内的多个缺陷不能当作多个独立章节**（在聚类统计中只贡献 **1 个独立聚类单元**）；
   - `$K_{\text{rep}}$` 仅用于测算模型重测稳定性，**绝不放大 $N_{\text{ch}}$ 或 $N_{\text{case}}$**。
3. **G1、G2-A、G2-B、G3、G6 全部强制采用章节级聚类置信区间**：
   - 主置信区间必须采用 **章节级聚类非参数 Bootstrap（按整章有放回重抽样 $B = 2,000$ 次，取 2.5%–97.5% 分位）** 或章节级聚类方差调整 CI（Design Effect / Rao-Scott 调整），并同步报告原始 `TP / FP / FN / TN` 与章节级宏观指标。
4. **`B = 2,000` 次 Bootstrap 只是数值重抽样计算，绝不能弥补独立章节数（$N_{\text{ch}}$）不足**。
5. **Precision 仅代表当前对应测试集分布，禁止外推至生产环境**：跨分布可迁移指标是 Recall 与 FPR。
6. **有序四级严重程度使用二次加权 Kappa（$\kappa_w >= 0.85$）**，附列原始 4×4 混淆矩阵与未加权 $\kappa$。

### 2. 阶段二：真实受控连载 + 多评委匿名文学盲评（全区间无空白三带裁决）

在 P0 离线 G1–G6（含 G2-A 与补齐后的 G2-B）全部通过、P1 工程测试全绿之后，**方可在获得作者明确批准后**开展同期对照真实创作验收（至少 2 题材 × 3 章 = `$N_{\text{ch}} = 6$` 独立章；对照组 = 现行 R3 基线，实验组 = R3 v3）：

1. **Blind Audit A（独立冷启动红队漏检审计）**：
   - 全新冷启动红队只读终稿（零原报告泄露），核查残余 `BLOCKER = 0`、残余 `MAJOR` 均值 **不高于同期基线**，并专项核查**高潮动作戏限知 POV 越界**是否被有效拦截。
2. **Blind Audit B（多评委匿名文学质量交叉盲评 + 绝对一致性 ICC）**：
   - **独立评委配置**：每批匿名随机洗牌稿件由 **至少 2 名完全隔离的独立冷启动评委**（推荐 2 名独立模型评委 + 关键样本真人作者抽核）各自独立评分、互不可见；
   - **锚定评分量表（Anchored Rubric）**：6 维（文笔语言、人物一致、情节节奏、场景沉浸、逻辑可信、综合完成度）1–10 分制，每一分档提供明确文字锚点，并附**两两偏好排序（Pairwise Preference）**与原文例证；
   - **评委间一致性（Inter-Rater Reliability）与分歧仲裁**：
     - **连续评分主指标**：采用 **绝对一致性组内相关系数 `ICC(A,1)` / `ICC(2,1)`**（参照目标 `>= 0.70`）；
     - **连续评分辅助指标**：**Spearman $\rho$**（辅助核验排序单调一致性）；
     - **偏好排序指标**：**Cohen's $\kappa$** 与原始一致率；
     - **强制仲裁规则**：若两位评委对同一章综合评分差值 **`>= 1.5` 分** 或偏好排序相反，**强制引入第 3 位独立冷启动仲裁评委**并公开原始分歧与文本证据。
   - **文学评分全区间无空白三带裁决规则**（设 $\Delta S = \bar{S}_{\text{v3}} - \bar{S}_{\text{baseline}}$，10 分制多评委仲裁综合均分差）：

| 均分差区间（全覆盖无空白） | 裁决状态 | 强制处理动作 |
|---|---|---|
| **$\Delta S \ge -0.20$**（且语域净化指标未退化、Blind A 零漏检恶化） | ✅ **PASS（通过）** | 文学无退化哨兵通过，允许保留当前提速与审稿配置 |
| **$-0.30 \le \Delta S < -0.20$**（灰区警戒带：下降 `0.20–0.30` 分） | ⚠️ **CONDITIONAL / HOLD（暂缓放行，归因复核与扩样裁决）** | **既不直接放行，亦不盲目一刀切回退**：① 强制逐章调阅多评委低分维度原文证据，判定属**机制性退化**（如说明书补丁/节奏断裂/热复用漏检）还是**单章随机叙事波动**；② 若检出明确机制性缺陷，直接判未通过并回退/修复对应开关；③ 若无明确机制性归因，**必须扩样加测至少 +1 题材 × 3 章（共 +3 章）重新盲评**，合并样本后仍 `< -0.20` 则强制回退 |
| **$\Delta S < -0.30$**（均分下降超过 `0.30` 分） | ❌ **FAIL / IMMEDIATE ROLLBACK（直接否决并立即回退）** | 立即回退对应提速或审稿开关（如热复用窗口或定级阈值），禁止合入主流程 |

   - **语域净化同步观测要求**：正文圆括号参数注释 **`= 0`**，`>40` 字长句占比压回题材健康区间（参照 `< 35%`，对比此前 `37%–52%`），盲评检出的“防杠说明书补丁 / 对白播报设定 / 返工文风断层”案例数低于基线组。*（注：6 章实测仅作无明显退化哨兵检验，不夸大为普适统计学证明。）*
3. **长篇跨卷实测（P1 验收阶段，仅在 3 章双轨通过后启动）**：
   - 跑通至少 1 个完整短卷（9–12 章），实测 L2（每 3 章弧审 + 每 5 章只读核查及临时安全门/工程硬阻断分轨）与 L3（正常卷审与发现跨章问题后的修复成本分账核算），验证 `diagnose_book.mjs` 与 `audit_story_state.mjs --readonly` 三重零写入及 `analyze_impact.mjs` 的实用价值。

## 三、明确的 Go / No-Go 停机规则

- **规则 1（离线不过不入仓，严禁混算 G2 与包装 `underpowered`）**：若 A / B / C 三方案在 P0-6 离线验证中均未能全过升级版 G1–G6（含 **G2-A 历史回归** 与 **G2-B 独立 Holdout** 分别达标，且 G2-B 不得处于 `underpowered`），**立即停机复盘根因或先补齐独立样本**，严禁强行合入主分支。
- **规则 2（效率不以文学断层或漏检恶化为代价）**：严格执行上表三带裁决——Blind A 漏检恶化或 $\Delta S < -0.30$ **立即回退**；$-0.30 \le \Delta S < -0.20$ **强制挂起归因与扩样验证**，绝不放行灰区退化。
- **规则 3（反虚报与证据分层纪律）**：任何阶段报告必须严格区分 **`工程测试通过` / `有限预算工程准入筛查通过` / `小样本实跑哨兵` / `普适文学质量或生产召回率证明`** 四层结论，严格标注 **`[真实运行日志]` / `[历史记录重建]` / `[理论估算]` / `[无法测量]`**，分列 `$N_{\text{ch}} / N_{\text{case}} / K_{\text{rep}}$` 与聚类 95% CI，严禁合并历史集与独立 Holdout，严禁凭情景权重+区间插值伪造理论 P50，严禁将静态扫描等同于运行期零写入，绝不将测试集 Precision 外推生产，亦不将 G6 筛查夸大为 90% 召回率统计学证明。
