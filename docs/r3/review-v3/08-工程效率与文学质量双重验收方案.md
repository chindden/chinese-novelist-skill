# 08 · 工程效率与文学质量双重验收方案

> **文档版本**：`v1.1 (Freeze-Ready Candidate)`  
> **核心纪律**：
> 1. **严禁将自动化单元测试通过、哈希校验通过或 CLI 加速描述为“文学质量提升”！**
> 2. **严禁混淆独立样本数量（$N_{\text{ind}}$）与重复运行次数（$K_{\text{rep}}$）**；所有统计验收指标必须报告原始 `TP / FP / FN / TN` 与 **95% Wilson 置信区间**。
> 3. 本方案强制实行**双轨独立验收（Track E 工程与效率验收 × Track L 审核准确度与文学质量验收）**——任一轨道未过线，均不得宣称 v3 架构验收通过或替代现行基线。

## 二、Track L：审核准确度与文学质量验收（三方案对照 + 统计稳健 G1–G6 + 多评委盲评）

### 1. 阶段一：P0-6 三方案离线对照与升级版 G1–G6 门禁（准入主仓硬门槛）

#### 1.1 三方案（A / B / C）同台对照与胜出裁决规则（不预设双阶段必胜）
在同一批验证集上并行评测：
- **方案 A**：增强单阶段完整审稿（生产底座 + v2.2 融合 + `precheck v2` + `PLANNING_CONFLICT_BLOCK` + 6 维最小取证槽）；
- **方案 B**：Pass 1 开放发现（含 6 维取证槽 + `NEEDS_SEMANTIC_AUDIT` 强制核销）+ Pass 2 独立轻量定级；
- **方案 C**：单阶段完整审稿（高召回偏置）+ 独立轻量定级复核（`PASS` 章短路跳过）。

**裁决硬规则**：
1. 仅允许**同时通过全部 G1–G6 门禁**的方案进入候选胜出池；若三者均未全过，立即停机复盘，**禁止强行合入主仓**。
2. 若**方案 B** 的 G1 或 G6 召回率低于方案 A 或 C 超过 `1.0 pp`、或出现任何 **1 例 `BLOCKER` 漏检**（证实“Pass 1 漏检无法被 Pass 2 找回”），**直接淘汰方案 B**。
3. 若多个方案同时全过 G1–G6，按优先级选优：**① G6 跨题材 `BLOCKER` 零漏检 & 召回最高 → ② G2 FPR 最低且三轮方差最小 → ③ 端到端审稿延迟最低**。

#### 1.2 统计规范硬要求（强制区分独立样本量与重复次数）
1. **严格区分 `$N_{\text{ind}}$`（独立样本数）与 `$K_{\text{rep}}$`（重复运行次数）**：对同一批样本重复运行 `K = 3` 次只能衡量模型重测稳定性（均值/极差/一致率），**绝不等于将样本量乘以 3**。
2. **强制原始四格与置信区间报告**：G1、G2、G3、G6 全部指标必须并列公布 **原始 `TP / FP / FN / TN` 计数**、**点估计**、**95% Wilson 二项置信区间**，以及 **Clear-tier（明确档）与 Borderline-tier（边界分歧档）分层统计**。

### 2. 阶段二：真实受控连载 + 多评委匿名文学盲评（唯一能检验文学质量的关口）

在 P0 离线 G1–G6 全部通过、P1 工程测试全绿之后，**方可在获得作者明确批准后**开展同期对照真实创作验收（至少 2 题材 × 3 章 = 6 章；对照组 = 现行 R3 基线，实验组 = R3 v3）：

1. **Blind Audit A（独立冷启动红队漏检审计）**：
   - 全新冷启动红队只读终稿（零原报告泄露），核查残余 `BLOCKER = 0`、残余 `MAJOR` 均值 **不高于同期基线**，并专项核查**高潮动作戏限知 POV 越界**是否被有效拦截。
2. **Blind Audit B（多评委匿名文学质量交叉盲评 + 评分一致性核验）**：
   - **独立评委配置**：严禁依赖单一评委下结论！每批匿名随机洗牌稿件由 **至少 2 名完全隔离的独立冷启动评委**（推荐 2 名独立模型评委 + 关键样本真人作者抽核）各自独立评分、互不可见；
   - **锚定评分量表（Anchored Rubric）**：6 维（文笔语言、人物一致、情节节奏、场景沉浸、逻辑可信、综合完成度）1–10 分制，每一分档提供明确文字锚点（避免宽严漂移），并附**两两偏好排序（Pairwise Preference）**与原文例证；
   - **强制评委间一致性（Inter-Rater Reliability）与仲裁规则**：
     - 连续评分报告 **ICC（组内相关系数）或 Spearman $\rho$**（目标一致性参照 $\ge 0.70$）；偏好排序报告 **Cohen's $\kappa$ 与一致率**；
     - 若两位评委对同一章综合评分差值 **`>= 1.5` 分** 或偏好排序直接相反，**强制引入第 3 位独立冷启动仲裁评委**并公开原始分歧与文本证据，绝不掩盖评委方差。
   - **通过哨兵标准（明确 6 章属小样本无退化哨兵，不夸大为普适统计学证明）**：
     - v3 组多评委仲裁综合均分**不得低于基线组超过 `0.2` 分**（消除此前 Arm 2 `-0.60` 分预警）；
     - 语域净化观测指标显著改善或维持健康：正文圆括号参数注释 **`= 0`**，`>40` 字长句占比压回题材健康区间（参照 `< 35%`，对比此前 `37%–52%`），盲评检出的“防杠说明书补丁 / 对白播报设定 / 返工文风断层”案例数低于基线组。
3. **长篇跨卷实测（P1 验收阶段，仅在 3 章双轨通过后启动）**：
   - 跑通至少 1 个完整短卷（9–12 章），实测 L2（每 3 章弧审 + 每 5 章只读核查与高危即时阻断）与 L3（正常卷审与发现跨章问题后的修复成本分账核算），验证 `diagnose_book.mjs` 与 `analyze_impact.mjs` 在真实长文本下的零误杀率与实用价值。

## 三、明确的 Go / No-Go 停机规则

- **规则 1（离线不过不入仓）**：若 A / B / C 三方案在 P0-6 离线验证中均未能全过升级版 G1–G6（尤其 G2 与扩大版 G6），**立即停机复盘根因**，严禁强行合入主分支。
- **规则 2（效率不以文学断层或漏检恶化为代价）**：若真实盲评（Blind Audit A/B）显示提速伴随漏检上升或匿名文学评分显著下降（`> 0.3` 分），立即回退对应提速开关。
- **规则 3（反虚报与证据分层纪律）**：任何阶段报告必须严格区分 **`工程测试通过` / `离线统计达标` / `小样本实跑哨兵` / `普适文学质量提升`** 四层结论，严格标注 **`[真实运行日志]` / `[历史记录重建]` / `[理论估算]` / `[无法测量]`**，凡样本量不足处一律明示置信区间宽度与统计边界。
