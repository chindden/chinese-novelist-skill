### 2. 完善统计独立性与评委一致性方法（影响：`07`、`08`、`README`）
- **区分三层样本维度**：在 `08` 与 `07` 明确分列 **独立章节数（$N_{\text{ch}}$）**、**独立案例数（$N_{\text{case}}$：`N_pos` / `N_neg`）** 与 **重复运行次数（$K_{\text{rep}}$）**，严禁混算。
- **显式处理同章多缺陷样本聚类问题**：在 `08` 1.2/1.3 节规定主置信区间采用 **章节级聚类非参数 Bootstrap（$B = 2,000$ 次按整章重抽样）** 或聚类方差调整 CI，同步报告章节级宏观指标，消除简单二项 Wilson CI 忽略章内相关性导致置信区间虚窄的问题。
- **明确 Precision 分布依赖性**：在 `08` 与 `07` 显式标注测试集测得的 `Precision >= 88.0%` **仅代表当前测试集正负比例下的表现，禁止直接推断或外推为生产环境 Precision**。
- **连续评分优先采用绝对一致性 ICC，Spearman 作辅助**：Blind Audit B 明确以 **绝对一致性 `ICC(A,1)` / `ICC(2,1)`** 为主一致性指标，**Spearman $\rho$** 为排序辅助指标，偏好排序采用 **Cohen's $\kappa$**。
- **有序四级严重程度采用加权 Kappa**：G4（及 `03` M-F、`07` P0-6）统一采用 **二次加权 Kappa（Quadratic Weighted Kappa, $\kappa_w >= 0.85$）**，同时附列原始 4×4 混淆矩阵与未加权 $\kappa$。
- **明确 G6 置信区间门槛的工程准入性质**：在 `08` G6 与 `07` P0-6 明确声明“点估计 `>= 90.0%` 且聚类 Bootstrap 95% CI 下界 `>= 75.0%`”仅为有限预算下的**工程准入验收规则（Acceptance Rule）**，**绝不得表述为“已在统计学上证明真实召回率达到 90%”**。

### 3. 进一步明确 L0 绝对零写入边界与临时安全门定位（影响：`02`、`03`、`04`、`05`、`06`、`07`、`08`、`README`）

### 4. 统一文学验收的评分边界（消除 `-0.20` 至 `-0.30` 空白带）（影响：`08`、`README`）
