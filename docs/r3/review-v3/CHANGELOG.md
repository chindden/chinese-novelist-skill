## `v1.1`（2026-11-25）—— 面向 PRD 冻结的六项针对性架构修订

### 1. 重新审视 5 分钟单章端到端性能目标（影响：`01`、`03`、`04`、`07`、`08`、`README`）
- **明确定位**：恢复并保留 **5 分钟单章端到端** 为 R3 的长期生产系统架构优化目标（North Star），同时明文规定其**不是写手必须遵守的限时指令**，严禁以限时压迫或降质换速度。
- **补齐 7 维度实际时间账本**：在 `03` 第三节拆解“模型推理与生成 / Agent 启动与排队 / 上下文读取 / 确定性工具执行 / 系统等待与交接 / 返工改稿 / 复审与冷重置”，并对所有数据严格加注四类来源标签：**`[真实运行日志]` / `[历史记录重建]` / `[理论估算]` / `[无法测量]`**（明确标注宿主不可测项 `TTFT`、`modelInternalThinkingTime`、`tokenGenerationSpeed`、`hostSubagentQueueWait`）。
- **核对两个历史耗时口径**：在 `01` 第三节与 `03` 第三节对照核验 **Step 3（`17.01–21.96 min`，磁盘时间戳历史记录重建，缺独立完整收尾）** 与 **Phase 1 Arm 0–2（`24.27–31.43 min`，实时 JSONL 全口径运行日志）** 及原 A/B 组（`7.06–8.59 min`，旧环境热复用重建），明确标记**计时口径与运行环境不一致，无法直接横向比较**。
- **深度研究 6 种替代架构与理论下限**：在 `03` 第三节逐项分析调用合并（M-A）、热复用+校准降熔断（M-B）、检查内聚（M-C）、收尾异步化（M-D）、审稿维度并行化（M-E）、辅助轻量模型路由（M-F）各自打击的时间账本段、预计节省量（标 `[理论估算]`）与质量边界；给出“一次通过章理论下限 `3.71–5.41m`、1 轮必要返工章理论下限 `5.51–8.71m`”的诚实推导，形成 S1（P0/P1 `8.5–13.0m`）→ S2（P2 并行/异步 `5.0–7.5m`）→ S3（协同模型演进 `<= 5.0m`）三阶段演进路线。

### 2. 补充双阶段审稿的三方案对照验证设计（影响：`02`、`03`、`06`、`07`、`08`、`README`）
- **破除“预设双阶段必胜”**：在 `03`、`07`（P0-5/P0-6）与 `08` 中将离线验证升级为 **A（增强单阶段完整审稿）vs B（Pass 1 开放发现 + Pass 2 独立轻量定级）vs C（单阶段完整审稿 + 独立轻量定级复核，PASS 章短路）** 三方案受控对照，三者共享 `precheck v2` 与 `PLANNING_CONFLICT_BLOCK` 底座以防归因混杂；明确未通过离线 G1–G6 门禁前严禁进入生产主流程。
- **专项解决“Pass 1 漏检后 Pass 2 无法找回”**：引入四重兜底——① `NEEDS_SEMANTIC_AUDIT` 强制核销清单；② `HL-1..HL-6` 6 维结构化最小取证槽（Fail-Closed）；③ 方案 B Pass 1 宽口候选契约（禁止自我以 `OR1–OR7` 隐藏疑点）；④ 硬性淘汰规则（若方案 B Recall 低于 A/C 超过 `1.0 pp` 或漏检任一 `BLOCKER` 直接淘汰）。

### 3. 修正统计验收设计并统一跨文档门槛（影响：`03`、`07`、`08`、`README`）
- **扩大 G6 跨题材独立 Holdout**：明确指出 4 章样本（Wilson CI 过宽）不足以证明 90% 召回率；将 G6 正式验收扩大为 **4–6 题材 × 合计 ≥12–16 章**独立未揭盲完整章节（独立双评委 + 第三方仲裁预建真值表，确保客观真缺陷 **`N_pos >= 30`**、独立非阻断 **`N_neg >= 40`**），要求 `BLOCKER` 漏检 `= 0`、综合 Recall 点估计 `>= 90.0%` 且 **95% Wilson CI 下界 `>= 75.0%`**、独立非阻断误阻断 `<= 13.0%`（明确档 `= 0`）；若阶段预算仅跑 8 章 Pilot 须显式标为 `underpowered` 不得宣称统计达标。
- **严格区分独立样本数 `$N_{\text{ind}}$` 与重复运行次数 `$K_{\text{rep}}$`**：删除原 `08` 中“或对现有 `n=33` 跑 3 次重复替代扩样至 `n>=60`”的错误等价表述；要求真实扩充独立非阻断样本至 **`N_ind_neg >= 60`** 并叠加 **`K = 3` 次独立重复**以分别测量统计精度与重测稳定性。
- **强制原始混淆矩阵与 95% 置信区间**：G1/G2/G3/G6 全部要求输出原始 `TP / FP / FN / TN`、点估计与 **95% Wilson 置信区间**。
- **完善文学盲评（Blind Audit B）多评委与一致性设计**：在 `08` 规定每批至少 **2 名完全隔离独立冷启动评委**（加关键样本真人作者抽核）+ 锚定评分量表 + 两两偏好排序，强制报告 **ICC / Spearman $\rho$** 与 **Cohen's $\kappa$**，同章分差 `>= 1.5` 或偏好相反时强制引入 **第 3 位独立仲裁评委**并公开分歧证据。
- **统一 G2 FPR 门槛**：消除原 `03`（`<=12%`）、`07`（均值 `<=15%`）、`08`（3 轮均值 `<=13.0%`、单轮 `<=15.0%`）三处口径漂移，全套文档严格统一为：**`N_ind_neg >= 60` + `K = 3` 轮，Clear-tier FP `= 0`，3 轮均值 FPR `<= 13.0%` 且任意单轮 `<= 15.0%`，Precision `>= 88.0%`**。

### 4. 修正全书机械诊断与预检的误判风险（影响：`02`、`03`、`05`、`06`、`07`、`08`）
- **完全重复段落、引号不配对、字数异常默认降为非硬伤非阻断（`advise` / `softWarnings`）**：
  - 重复段落（D5）兼容时间循环、多视角叙事与回环意象；
  - 引号排查（D4）内置中文跨段多段引语白名单（前段无闭引号属合规排版），剩余疑点亦仅标 `advise`；
  - 字数异常（D3）彻底遵循作者铁律：**严禁为了死磕字数牺牲内容完整性**。
- **确立确定性阻断唯一准入原则**：仅 **客观工程文件破损** 与 **作者在配置中显式设定的硬约束** 才允许在 L1 `precheck v2` 触发确定性阻断；L0 输出分级收紧为 `integrity_alert` / `high_risk_fact_alert` / `advise` / `note` / `pass` / `skip`，永不凭统计异常自动阻断文学通过。

### 5. 明确四层审核的触发与成本边界（影响：`02`、`03`、`04`、`05`、`06`、`07`、`README`）
- **高危事实冲突当章即时阻断，绝不等到下一次故事弧审核**：修正原 `04` 将第 5/10 章 `FACT_CONFLICT_CANDIDATE` 拖到第 6/12 章弧审处理的设计漏洞；建立三类异常分流表（类别 I 普通机械告警并入 L2/L3、类别 II 高危事实冲突与 `STALE_REVIEW_AFTER_EDIT` 当章即时拦截、类别 III 卷级宏观文学问题归口 L3）。
- **L3 卷审成本拆为两笔账独立核算**：区分 **L3-A 正常卷审**（`4–7 min/卷`，20 章摊销 `0.20–0.35 min/章` `[理论估算]`）与 **L3-B 发现问题后的修复+复审成本**（轻度 `+1–3m/卷`、中度回改 1–2 章 `+10–25m/卷` 摊销 `+0.50–1.25m/章`、重度 3+ 章 `+30–60+m/卷`，不含人工审批等待）。
- **彻底解决每 5 章脚本写入与 L0 只读原则冲突**：明确 L0（`diagnose_book.mjs` 与每 5 章 `audit_story_state.mjs --readonly`）默认 **0 字节磁盘写入（纯 stdout）**；诊断派生缓存仅在编排层显式传 `--cache-file` 时写隔离缓存目录，里程碑归档由事务层 `r3_ops.mjs record-milestone` 单独落盘至 `reviews/r3/milestones/`，实现只读监测与事务落盘物理隔离。
