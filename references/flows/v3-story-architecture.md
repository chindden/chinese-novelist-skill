# V3 四级长篇故事架构与题材路由

本文件在原版 `phase2-planning.md` 的人物档案、写作计划、文风基准与章节摘要上增加长期规划。**不能将十章三幕式模板机械拉伸为一百章。**

## 四级结构

1. **全书（story promise）**：核心卖点、贯穿问题、主角外在目标和内在需要、结局成本。
2. **分卷（volume）**：本卷目标、对手和制度性摩擦、阶段兑现、不可逆后果、下一卷的新问题。
3. **故事弧（arc）**：数章连续的触发→尝试→受阻→选择→后果；长度依题材而定，非强制爽点配额。
4. **章节（chapter）**：角色眼前目标、行动和阻碍、叙事信息、关系/事件/认知有效变化、节奏用途与结尾期待。

只细化近期章节；远期以承诺和重要因果为锚，避免刻板锁死后半部剧情。决定修改既有世界规则时，先评估历史章节影响和账本后果。

## 前三章按题材组织阅读动力

| 类型 | 应优先建立 | 避免套用 |
| --- | --- | --- |
| 仙侠/玄幻 | 世界规则、求生或成长压力、试探、代价 | 必须系统、必有反杀 |
| 悬疑/惊悚 | 异常证据、谜题、认知变化、可信调查 | 无证据连续反转 |
| 历史/权谋 | 利益格局、身份制约、策略抉择、政治成本 | 全体对手降智 |
| 都市/现实 | 具体愿望、职业困境、关系转折 | 强行生死倒计时 |
| 科幻 | 技术/自然规律造成具体行动问题 | 先上设定百科 |
| 言情/情感 | 两个有自主目标的人、关系张力、期待 | 强制造误会 |

不规定第1章必须生死危机、第2章验证金手指、第3章反杀。共同标准：**故事承诺初步兑现、人物值得关心、读者形成下一章期待**。

## 人物生命力

每名关键人物至少记录：当下欲望、不能明说的私心、恐惧/误判、愿意承受的代价、近期已发生的损失、与他人的动态关系。配角必须拥有与主角不完全重合的目标。允许人物不理性，不能仅用“利益最大化”衡量其可信度。

## 世界规则与资产

奇幻/科幻适用时建立能力边界、代价、资源流入与产出上限；现实题材使用职业/金钱/关系/制度约束，不凭空引入战力系统。所有关键数字、时间、物品归属和知情边界用原版事实词典做唯一真相来源，不重复维护冲突表。

## 三类规则

- **硬约束**：已确立事实、时间、物品、信息可得性、世界规则和关键因果。
- **审稿原则**：可信动机、有效变化、文风、节奏、悬念与期待兑现，需要引用具体正文判断。
- **可选技巧**：固定字数钩子、每N章爽点、金手指、UI 面板、对话长度上限，按题材决定，不能全部硬性要求。
